# Digital Twin for Windmill – Predictive Monitoring System

## Overview

This project is a web-based Digital Twin Dashboard developed for monitoring a wind turbine in real time. It visualizes sensor values, analyzes machine health, predicts possible failures, estimates energy consumption and energy loss, and displays a 3D digital representation of the windmill.

The current version simulates sensor readings. It is designed so that simulated values can later be replaced with live sensor data from an actual wind turbine.

## How the System Works

1. The system receives machine sensor values.
2. Temperature, vibration, and RPM are updated every interval.
3. The dashboard displays current sensor values.
4. The graph is updated continuously.
5. The 3D windmill changes its blade speed according to RPM.
6. The windmill changes color depending on machine health.
7. Previous sensor readings are stored.
8. After collecting sufficient readings, predictive maintenance begins.
9. The system estimates:
   - Failure probability
   - Machine health
   - Energy consumption
   - Energy loss
10. If danger thresholds are exceeded:
    - Warning message appears
    - Windmill turns red
    - Continuous alarm starts

## Prediction Logic

The prediction module analyzes:

- Temperature trend
- Vibration trend
- RPM fluctuations
- Previous sensor history

The system waits until enough historical data is collected before generating predictions.

Possible outputs:

- Safe
- Warning
- High Risk
